## 2026-09-22 - [CRITICAL] Flutter InAppWebView Permissive Configuration
**Vulnerability:** The application was using an insecure and overly permissive `InAppWebViewSettings` configuration in `lib/main.dart` which included `mixedContentMode: MixedContentMode.MIXED_CONTENT_ALWAYS_ALLOW`, `safeBrowsingEnabled: false`, and enabled both universal and file access from file URLs.
**Learning:** These settings, while often copied from tutorials or used to bypass immediate development hurdles, open the application to severe security risks including Man-in-the-Middle (MITM) attacks by allowing HTTP resources on HTTPS pages, and potential local file access vulnerabilities. Using these defaults negates key WebView protections on Android/iOS.
**Prevention:** Always follow the principle of least privilege for WebViews. Ensure `mixedContentMode` is restricted (`MIXED_CONTENT_NEVER_ALLOW`), enable safe browsing (`safeBrowsingEnabled: true`), and explicitly disable `allowUniversalAccessFromFileURLs` and `allowFileAccessFromFileURLs` unless there is a strictly documented and verified requirement.
